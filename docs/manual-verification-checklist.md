## 验收条目

### 1. 启动与一级界面

- [ ] `npm run tauri dev` 启动后出现窗口,标题 "AutoCompress"
- [ ] 顶部显示菜单栏(标题 + "设置"按钮)
- [ ] ffmpeg 状态条: 红色显示 "ffmpeg 不可用",右侧有"重新检测"按钮
- [ ] 目录列表显示 "目录列表 (0)" 和 "＋ 添加目录" 按钮
- [ ] 点击 "＋ 添加目录" → 弹出输入框 → 输入存在路径 → 卡片出现
  - 无效路径或无配置文件 → 显示 `● 无效(无配置文件)`
- [ ] 点击 "设置" → 弹出全局设置弹窗

### 2. DirCard 卡片四态

- [ ] **有效(无排程)**: 配置存在,但 schedule.time 为空 → 显示 `● 有效(未排程)`
- [ ] **有效(已排程)**: 配置存在且有 schedule.time → `● 有效`
- [ ] **配置错误**: JSON 格式错误 → `● 配置错误` + 错误信息
- [ ] **重叠**: 目录是其他目录的子目录/父目录 → `● 重叠`

### 3. 进入二级界面

- [ ] 点击 DirCard → 进入二级界面,顶部显示返回栏 + 目录路径 + "立即压缩"按钮
- [ ] 摘要区显示匹配文件数、参数名称、下次执行时间、循环风险数
- [ ] 三个 tab: "压缩文件预览"(默认)、"配置"、"压缩执行历史"
- [ ] 点击 "← 返回" → 回到一级,卡片刷新

### 4. 压缩文件预览 (TabPreview)

- [ ] Tab默认选中"压缩文件预览"
- [ ] 表格显示: 原文件 / 压缩后 / 大小 / 风险
- [ ] 各列与配置文件匹配
- [ ] 无匹配文件时显示 "无匹配文件"

### 5. 配置 (TabConfig)

- [ ] 表单显示: 调度、压缩参数、include、exclude、filters、rename_rules
- [ ] 白名单(include)为空时点保存 → 表单底部红色提示
- [ ] 选择模板/自定义参数切换正常
- [ ] 保存成功后弹窗消失
- [ ] 外部修改 config.json → 表单自动重载(mtime 轮询)

### 6. 压缩执行历史 (TabHistory)

- [ ] 开始为空显示 "暂无执行记录"
- [ ] 执行压缩后有记录显示
- [ ] 展开可看文件级详情

### 7. 全局设置

- [ ] 点击菜单栏"设置" → 弹窗出现
- [ ] 修改 ffmpeg 路径 → 保存 → ffmpeg 状态条更新
- [ ] 修改超时时间 → 保存生效
- [ ] 模板增删改 → 保存后 TabConfig 模板下拉更新
- [ ] 开机自启动复选框 → 保存生效
- [ ] 最小化到托盘复选框 → 保存生效
- [ ] 取消按钮关闭弹窗不保存
- [ ] 点击蒙层背景关闭弹窗

### 8. 调度与压缩

- [ ] 设 schedule.time = `now+2min` → 2分钟后自动触发压缩
- [ ] 严格不补跑: 压缩触发后 nextRun 推至明天同点
- [ ] "立即压缩"按钮 → 立即触发压缩,不重置 nextRun
- [ ] 串行锁: A 压缩中点击 B 的立即压缩 → 提示 "已有目录正在压缩"
- [ ] A 完成后 B 自动执行(秒级延迟)

### 9. 弹窗确认

- [ ] 压缩中点击关闭窗口 → 弹窗 "正在压缩,确定退出?"
- [ ] 点击 "继续等待" → 窗口不关闭
- [ ] 点击 "强制退出" → 窗口关闭,进程退出
- [ ] 非压缩中关闭窗口 → minimize_to_tray 时隐藏到托盘,否则退出

### 10. 命令行 --run-once

- [ ] 构建后: `cd src-tauri && cargo build`
- [ ] `./target/debug/autocompress.exe --run-once` → 无窗口,对所有已启用有效目录执行一次压缩,然后退出

### 11. 系统托盘

- [ ] 启动后托盘区出现图标
- [ ] 右键菜单: "显示主窗口" / "退出"
- [ ] 点击"显示主窗口" → 窗口显示
- [ ] 点击"退出" → 进程退出
- [ ] 最小化到托盘: 关闭窗口 → 隐藏到托盘

### 12. 日志

- [ ] 压缩后在 `<目录>/.autocompress/logs/` 生成 `run_*.log`
- [ ] 日志包含人类可读文本和末尾 JSON 块
- [ ] JSON 块可解析出完整执行摘要
- [ ] 日志保留天数设置生效
